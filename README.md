# 🧮 Python Taschenrechner

Ein kleines Python-Projekt, das die Grundrechenarten unterstützt: Addition, Subtraktion, Multiplikation und Division.  
Dieses Projekt ist ideal für Anfänger, um **Schleifen, Bedingungen und Benutzereingaben** zu üben.

---

## 🚀 Features
- Addition ➕  
- Subtraktion ➖  
- Multiplikation ✖️  
- Division ➗  
- Wiederholbare Berechnungen in einer Schleife  
- Fehlerbehandlung für ungültige Eingaben (`try/except`)
